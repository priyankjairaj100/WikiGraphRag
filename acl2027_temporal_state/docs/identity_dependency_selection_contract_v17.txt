Visible identity dependency candidate selection v17
Declared before this selector reads any original source body. This is a separate
pre-authoring population supplement, not a modification to the101 table/neighbor
render protocol or to any selected financial table. It creates no question,
reference, source-admitted card, natural model response or visibility certificate.

Motivation and fields

The preserved v16 mechanical cards copy six DEI values but omit hidden flags.
The separate source-free provenance audit records this gap. Required new card
fields are visible issuer/registrant name, report type and report-end/date wording.
Optional CIK, fiscal-year focus and fiscal-period focus are excluded from this
selection and future author cards unless separately supported by visible source.
An end date does not infer fiscal-year identity. Exact source hash identifies the
physical object, not independent legal identity, SEC-byte equivalence or truth.

Frozen candidate rule

Use all12 exact sources and manifest order from table_view_protocol_v16_1. Verify
all hashes/byte lengths before selection. Use the unchanged independent Expat/
lxml expanded-name locator and original byte-span checks from build_table_views_v16
and the frozen v15.1 byte parser. Do not normalize or rewrite source bytes.

Inspect original ix:nonNumeric nodes whose resolved QName namespace begins with
http(s)://xbrl.sec.gov/dei/ and local field is EntityRegistrantName, DocumentType
or DocumentPeriodEndDate. Unresolved namespaces, missing nodes, empty or conflicting
DEI strings leave that field unavailable. Exact normalized strings use NFKC,
case-folding and Unicode-whitespace collapse; no fuzzy aliases or punctuation
deletion. Repeated equal declarations may supply multiple candidate blocks.

Reject target nodes with recognized hiding on themselves/ancestors or descendants.
The hiding profile includes ix:header/ix:hidden, HTML hidden, inline display:none
and visibility:hidden/collapse. Computed CSS and image text remain unverified.
No hidden DEI node is extracted and made visible. For issuer ONLY, and only when
every original DEI issuer node is recognizably hidden, search exact normalized
visible subtree text equal to that one declared name. Candidate match elements
are p/div/h1-h6/table/span/font/b/strong/em/i/td/th, with original span <=16KiB.
No issuer fallback when the DEI name is simply absent, conflicting, or visible
but its containing block is ineligible. No text fallback for report type/date.

For each target/match, inspect itself and at most seven successive ancestors.
Choose the nearest eligible whole p/div/h1-h6/table. An eligible original block
has <=16,384 bytes, <=1,500 Unicode-whitespace-collapsed text characters, <=256
elements and <=16 ix:nonFraction occurrences; contains no script/style element,
nested table or recognized hiding cue anywhere in its subtree or ancestors;
and has nonempty text. Preserve entire selected block and original ancestors.
The limited block is a candidate, not proof that labels/dependencies suffice.

Deduplicate eligible blocks by exact DOM path per field, order by original byte
start and select the first2. Never replace failed renders with later candidates.
Union identical selected blocks across fields, retaining all field links; this
produces at most6 unique blocks/source and72 overall. Keep all field denominators:
12 sources,36 required field slots, up to72 candidate slots. Report absent fields,
all syntax/size rejection counts and eligible-not-selected counts. All candidates
remain pending actual rendering and independent source/CSS/identity review.

Interface and storage

Public result.sources use renderer-compatible records:
 {source_path, external_filename, source_sha256, source_bytes,
  blocks:[{block_id,dom_path,anchor:{byte_start,byte_stop,span_sha256},
           role:identity_dependency_candidate,identity_fields:[...]}],
  identity_fields:[per-field candidate status/count/reason records]}.
No public field carries the actual name/date/DEI value or block text. A separate
private per-source file holds whole selected block text and matching node anchors
for later review. Keep that directory outside Git. Aggregate private payload cap
25,000,000 bytes minus65,536 metadata reserve; refuse rather than truncate.
Output protocol/result/attempt directories cannot overwrite prior paths. No
symlink source or unconstrained source filename is admitted. Source errors retain
all three required field failures and do not erase other source records.

Before first selection, run authored controls and obtain independent source-free
review. The review must have status passed_authored_review, no open_blockers and
code_bindings matching every listed selector/helper/decoder/test/contract file.
Freeze a new protocol binding that receipt, code, input metadata, source pins and
Python/lxml identity. This freeze does not inspect source values. Run the frozen
all12 selection once, preserving unavailability without threshold retuning.
Execution requires exact complete code/input binding-key sets, a currently closed
hash-matching independent review, and ordered source/denominator equality to the
bound parent manifest. An empty or shortened protocol cannot report a twelve-
source success. Any empty DEI declaration blocks that field even when another
declaration is nonempty; do not discard empty declarations before consistency
checking. Both rules were independently checked before the first source pass.
