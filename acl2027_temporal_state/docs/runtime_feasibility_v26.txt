The tokenizer must count the complete rendered prompt before each completion.
The complete prompt and output allowance must fit without truncation.
The KV cache uses Q8_0.

The process has a six-GiB address-space limit.

The request limit is 600 seconds.
The process limit is 7,200 seconds.
Generation uses greedy decoding and seed 260026.
Native reasoning is disabled.

The request schema permits id, messages, and optional output_schema only.
