Scope and independence
The reviewer inspected the v0.6 source-only protocol, accepted neutral scoring
request, objective/cache documentation, current decoder objective and local-link

Provisional disposition
A pinned small-model likelihood pass is a useful execution and score-sensitivity
milestone if all raw input/token/logit provenance is retained. It is not yet a
comparison supporting the proposed ACL research claim. The repaired graph has
seven resolved readings for seven mentions; alternative resolved identities are
absent. A fresh source-only audit should be permitted to return zero justified
alternatives. Inventing ambiguous candidates to induce a joint-search difference
would invalidate the empirical motivation. This pilot also has no correction or
essential-support edges, so it cannot compare correction-sensitive objectives.

Score target and construction
Each score must concern faithful interpretation of its historical source, not
whether that source statement remains true after a later correction. A link is
judged conditional on endpoint admission. Planned CHANGES must be judged as
planned succession within the endpoints' shared modality; requiring an already
observed actual transition would silently change the target on this graph.

Binary support log-odds are real model-derived numerical features when collected
from actual next-token probabilities. Their common unit does not establish a
common semantic calibration across readings, links, unresolved, and no_link.
Separate binary prompts need not produce mutually consistent judgments or a
categorical probability distribution over mutually exclusive alternatives.
Adding the potentials defines an energy objective. A constrained distribution
could be defined mathematically from that energy, but it would not thereby be
the language model's joint posterior, calibrated factual confidence, or answer
probability. Correlated sources and repeated mentions may still be counted more
than once. More candidate alternatives can change the abstention prompt itself.

The unresolved item asks whether no single supplied resolved reading is adequate.
It is not the factual negation of every resolved proposition. The no_link item
asks whether none of the proposed outgoing relationships is supported. The
implementation nevertheless assigns one common no_link potential to a mention
for every selected reading, including unresolved. When all outgoing links are
inadmissible because an endpoint is unresolved, that no_link value can still be
negative because an otherwise plausible relationship exists. This is a declared
heuristic compatibility mismatch, not a code arithmetic failure. It can affect
whether an endpoint is resolved and must remain explicit in interpretation.

For a singleton resolved candidate with a perfectly complementary abstention
judgment, scoring both binary odds would double the resolved-versus-unresolved
margin compared with a single supported-versus-zero score. With multiple links
and independently worded abstention prompts no such fixed relationship need
hold. Therefore the v0.7 explicit-null path must not silently borrow the unused
v0.6 likelihood proposal's zero-reference convention. Beta, penalties, label
mapping, aggregation across label orders, and primary versus diagnostic scores
must be fixed before inspection. Do not select whichever coding yields a gap.

Execution and reproducibility requirements
Record immutable model revision and exact GGUF hash, tokenizer metadata/tokens,
runtime/library binary hashes and build provenance, CPU/thread/precision/context
settings, prompt serialization, actual chat template and thinking setting,
input token IDs, and label token IDs. Both label continuations must start from
identical context state. Teacher-force every continuation token; record its
conditional log probability using the complete vocabulary normalizer. Preserve
both display-order conditions. A sampled token's confidence cannot stand in for the
unobserved alternative. Top-k-only logits cannot establish the normalizer.

The total unnormalized label mass P(Yes)+P(No) should be reported along with the
signed log-odds. Strong conditional Yes/No preference is compatible with very low
absolute probability of either label, for example under a mismatched response
format or thinking prefix. Do not discard low-mass items or repair prompts after
viewing values without declaring a separate exploratory attempt. Include every
failed or truncated attempt, and fail rather than silently truncate sources.

Pinned scoring does not pin the earlier unversioned candidate generation and
validation-triggered repair. Correct provenance is a reproducible scoring stage
on an archived unversioned graph, with its full candidate lineage retained.
Byte-identical deterministic cache replay is distinct from model regeneration.
An observed numerical regeneration tolerance must be stated with hardware and
runtime scope; bitwise portability across environments must not be assumed.

Attribution boundary
Within one frozen cache, matched decoders differ in search alone. They share
candidate coverage, scoring, temporal feasibility, and correction policy. The
independent baseline already performs exact conditional link optimization;
calling it purely independent edge selection would understate that baseline.
A greater objective can establish better optimization only. With no gold it
cannot establish better factual inference, extraction, abstention, or answers.
A v0.6-to-v0.7 output change also changes model, score family, item prompting,
and possibly label treatment. It is a score/backend sensitivity observation,
not an algorithmic improvement or causal calibration result.

Publication decision
Even a successful local run leaves the research gate unchanged: multiple
independent histories; supported competing readings and candidate recall;
source adjudication; frozen held-out evaluation; strong contextual baselines;
error decomposition by extraction, score, and search; factual answer metrics;
and a scalable inference contribution if joint search is the main claim.
Development repairs and retrospective source-availability uncertainty stay in
the paper's limitations. Repeated implementation checks cannot substitute for
those measurements. A null ambiguity audit is useful evidence to change data
collection priorities, rather than a reason to force a positive example.

Clarification: full-context ambiguity is not candidate proposal recall
The v0.7 audit requires two mutually exclusive readings to remain defensible
within the full supplied source context. This is a deliberately strict test of
residual semantic ambiguity. It is not a test of whether a local proposal model
could reasonably produce several hypotheses before cross-document or global
constraints resolve them. Globally falsifiable but locally plausible hypotheses
can be legitimate candidates; excluding all of them before inference can screen
out exactly the resolution problem the proposed system should study.

Accordingly, zero alternatives in this audit does not establish that joint
inference is unnecessary. The next study should separate (a) local-window
candidate proposal coverage and precision, (b) resolution using the full source
prefix, and (c) global search on one shared candidate union. Fallible proposals
are permitted; gold-driven pruning and invented source facts are not. Compare
against a strong full-context unary scorer and give matched decoders identical
candidates and scores. Natural source ambiguity, model uncertainty, proposal
error, and globally resolvable uncertainty must be reported as distinct cases.
No frozen v0.6/v0.7 graph or score protocol is changed by this clarification.

Recommendation: a controlled document-prefix primary task
A defensible primary benchmark can use immutable retrieved document versions
with explicitly experimental delivery order and cutoffs. This evaluates what
follows from the supplied record stream, not what was publicly knowable at a
historical instant. Keep delivery index/time, document-reported publication
time, event time, and present retrieval time as separate fields. Freeze admission
and delivery order before labels or model scores. Every method receives the same
prefix, and reference answers must express record-supported facts, conflicts,
unknowns and unrealized plans rather than omniscient real-world truth.

This task removes historical first-public-availability certification as a gate
for the controlled primary benchmark while narrowing the conclusion honestly.
Current document versions may contain later revisions; they cannot authenticate
historical public knowledge even when their hashes are fixed. Document that
limitation, inspect whether an alleged original/correction pair still exposes
the original assertion, and never claim a predictive historical backtest.
A separately certified historical-replay slice can test external realism later.
This recommendation does not alter any existing source cutoff or replay result.

do not average, clip, tune or discard scores to obtain a preferred outcome.

Final decoder-result disposition
The completed adapter reports 16 decodes: two score conditions, two objectives,
and four search methods. I read the saved result and independently recomputed
all 16 selected-state additive totals directly from the derived cache scores;
they match within 1e-12. Both objectives coincide here because the graph contains
no correction or essential-support edges. No gold, QA, or answer metric is used.

In the fixed primary yes_no condition, all four methods select all seven resolved
readings and the same three links (l9, l1, l14), with objective
70.57755028217798 and exact gap zero. There is no primary search advantage.

In the diagnostic no_yes condition, independent selects r2, r4, r6, r7 with
link l12, giving -7.7397231459617615. Iterative, iterative with restarts, and
exact joint select r2, r4, r5, r6, r7 with link l14, giving
-7.622846573591232. The independent exact gap is 0.11687657237052917; all three
other methods have zero gap. Relative to independent, accepting r5 costs
0.016431838274002075 in unary score and replacing l12 with l14 gains
0.13330841064453125 in link score. The net gain exactly explains the observed
optimization difference. Ordinary iteration already closes it; the result does
not motivate a new exact-search algorithm by itself.

All eight method/objective pairs change selected states across the two conditions.
These are condition-dependent optima under uncalibrated scores. Comparing the
raw objective totals across conditions has no accuracy meaning. Promoting the
diagnostic gap while omitting the primary zero gap would misrepresent the fixed
primary/diagnostic design. Adding r5 is not called an accuracy improvement: no
independent reference evaluation was performed, and the entire candidate graph
still has only one resolved interpretation per mention plus abstention.
