SOURCE ANNOTATION EXTENSION — v0.9

Four new development histories cover Disney, Intel, CVS and Artemis. All eight selected source URLs yielded usable current captures, frozen into two cumulative document prefixes per history before annotation and question generation. New captures remain new versions even when hashes match the preceding checkpoint. The delivery order is an experimental document order, not certified historical public availability.

Eight isolated conversational annotation roles produced 123 claim instances. Separate source-only reference roles saved seven files containing fourteen judgments over eight question texts. One Disney second-prefix reference write was blocked by a content filter without a specific policy explanation; no artifact was written, no retry or substitute was generated, and its findings reported in chat were not promoted into reference labels. The failure receipt is data/source_stream_v09/generation_failure.json.

All fifteen saved raw outputs passed the existing v0.8 schema, exact Unicode span, request-hash and eligible-source checks against the new v0.9 capture/delivery manifests. Two separate source-only review roles then checked their semantic interpretations, with additional model cross-checks for Intel second-prefix and Artemis. Shared training and unavailable model revisions limit reviewer independence. This is model-assisted development work, not human gold.

One annotation was revised once. Disney second-prefix assigned an exact Executive Chairman start day from present-tense wording and an article dateline without explicit effective timing for that role. Review removed the day constraint and recorded uncertainty, retaining the separately supported month-level retrospective statement. All seven reference files and seven other annotations were retained unchanged. All fifteen final selections passed the original validators. Raw and reviewed artifacts remain distinct.

The selected annotations contain 123 claim instances, zero explicit factual corrections, and four change links. These are repeated-prefix records rather than 123 independent facts. The fourteen reference judgments comprise seven supported and seven not-established answers. Future announced dates do not establish completed events; later role descriptions do not independently confirm exact earlier start days; co-chief-executives require a representation that permits shared roles. Ordinary succession and plan revision are not labelled CORRECTS.

Together with v0.8, seven histories have fourteen reviewed prefix annotations (180 claim instances). Thirteen of those fourteen prefixes have saved reviewed reference files, containing twenty-six judgments. Six histories have both reference prefixes complete; Disney remains incomplete at its second reference prefix. These counts do not include older, differently constructed natural or authored pilots and do not establish independence, benchmark admission, candidate recall or model accuracy.

The package carries thirty compact initial/final projections plus source and generation receipts. Evidence spans retain source IDs, offsets, quote lengths and hashes; full source text, quote-bearing requests/outputs and prose notes remain outside the package. The default replay checks metadata integrity only, including 700 repeated evidence-hash entries; it cannot verify exact quote occurrence without matching full source texts. A future public download can differ. No executable candidate projection or QA decoder comparison was run on these new histories.

Reproduce packaged checks:
  python scripts/verify_source_capture_v09.py
  python scripts/source_stream_v09.py replay

With matching external inputs, the source-only requests can be fully validated by scripts/source_stream_v09.py validate --working-root <working-directory>. The completed generation/review records are frozen; publication of compact projections is not a new model execution.
