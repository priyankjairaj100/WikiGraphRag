Next research steps after v0.10

Working contribution: source-grounded correction attribution and selective preservation of supported answers. This is a testable direction, not established novelty or a promised ACL acceptance.

1. Complete the evidence gate.
Preserve the failed capture batch. Resume full-document acquisition only when a working authorized transport is available, recording new retrieval versions rather than replacing failure receipts. Capture actual earlier versions plus explicit corrections, and separate publication metadata from retrieval and controlled delivery. The financial cases remain redundant-propagation controls.

Freeze a new bounded search tranche before executing it: at most three queries per domain, at most six newly inspected histories overall, and at most four authored documents per candidate. Seek source-present conclusions that rely essentially on a corrected premise but are not themselves explicitly replaced; also seek conclusions retaining independent support. Exclude invented thresholds and guessed causal links. Natural occurrence, exact evidence, authority, scope and version availability must all be adjudicated. Report shortfall; do not fill a nominal quota with manufactured cases.

2. Specify support answering before a model comparison.
The current API requires an event date and cannot turn an unknown interval into a definite timeless answer. Design a separate document-state query contract for the status of a source-reported assertion or its surviving evidence. Distinguish support withdrawal from falsity, value recomputation and real-world temporal succession. Retain unknown event bounds. Define supported, withdrawn and unresolved evidence states precisely; add a contested state only with explicit semantics and data that require it.

Start with the smallest adapter needed by admitted examples. Use immutable assertion IDs, correction provenance and evidence-source IDs. Keep the current AND-only graph limitation explicit. Multiple independent support paths require a reviewed OR-support representation; do not implement that extension merely to add complexity. Classical truth-maintenance/provenance algorithms remain required baselines.

3. Freeze a matched empirical comparison.
After admission, prepare independent source-only proposals and separate answer/evidence references. Log model-assisted adjudication and unresolved disagreement; do not call it human gold. Retain every directly stated correction in every applicable baseline.

Every system must receive the same exact source representation and delivery order. A source-only full-prefix reader receives no candidate graph or labels. If complete documents exceed context, either select a backend with verified capacity or declare a new fixed passage task before predictions; never silently trim a full-document condition. Retrieval variants must share a common collection and budget, and report retrieval recall separately.

Use the same candidates and actual score cache across independent, iterative, restarted and bounded exact decoders. Cross no withdrawal, direct withdrawal and dependency-aware withdrawal only where those policies have source-grounded inputs. The pinned 4B path is available, but its prior false role acceptance means model size and order stability alone are insufficient validation. Preserve malformed outputs, failures and uncertainty.

4. Decide whether an algorithmic paper is warranted.
Primary unit: history. Evaluate downstream answer/evidence correctness jointly with unaffected-answer retention; report denominators, abstentions, changes in retrieval access and resource costs. Separate correction-policy gain from candidate/scorer improvement and from exact-search gain. A small development result only licenses a larger independently held-out study; it is not a publication result.

Advance solver work only after actual useful residual failures survive the strongest competent reader/direct/iterative baselines. If all admitted examples are already solved by direct correction, pursue a source-grounded evaluation/resource contribution only if scale, annotation quality and task distinctiveness justify it. Preserve negative controls and revise the paper's claim rather than removing strong baselines.

5. Maintain the paper and reproducibility package.
Keep every claim linked to immutable artifacts; retain the v0.9 scoring limitations and unresolved Disney reference artifact. Compile and visually inspect the full manuscript only after the experiment table is defensible. Verify current ACL/ARR instructions before submission preparation; project target dates are planning assumptions, not newly verified deadlines. Submission and paid cloud compute have not been initiated.
