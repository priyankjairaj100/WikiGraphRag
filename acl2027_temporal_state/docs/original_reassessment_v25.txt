What the original paper actually contributes

Original title:
Reading the Latest, Not the Loudest: Lifecycle-Aware Structured Memory for Retrieval-Augmented Generation.

The useful idea is to resolve obsolete evidence before the reader receives its context.
A later claim can remove an earlier claim from retrieval eligibility.
The method compares subjects, relations, values, and timestamps through fixed text rules.
It creates directed supersession edges.
The retriever applies a hard mask before selecting its first five claims.
The interval extension groups connected claims and sorts their timestamps.

This is a clear problem statement and a useful baseline.
The graph representation is not the essential innovation.
The essential intervention changes which evidence can enter the context.
Keep this intervention as the link between the original and revised papers.

The present evidence cannot support a broad ACL method claim

1. Much of the original corpus already encodes the desired change structure.

FreshRAG contains 304 generated claims across 100 keys.
Its policy values increase through generated histories.
It sometimes repeats the final value.
Real-world contains 56 rendered claims across 20 curated keys.
Wikidata contains 208 rendered claims across 73 keys.
Wikidata-prose rewrites those same 208 claims.
These datasets are not independent natural document collections.

TempLAMA contains 747 rendered claims across 300 changing keys.
The builder reads the first answer from each original answer list.
It collapses consecutive years with the same answer.
It excludes groups without two different values.
It selects the first 300 qualifying keys in sorted order.
It fills the original query template with the selected answer.
Thus, its source labels are external, but its retrieval task is constructed.
Collapsing repeats removes cases that challenge the submitted interval algorithm.
Selecting one answer does not establish that each original relation is functional.

Three possible pivots

Pivot 1: Answer reuse after observed evidence changes.

Research question: Which cached answers require another retrieval and reading pass after a real document update?
Keep the previous answer's cited evidence and retrieval record.
Compare changed source passages with those dependencies.
Use a conservative detector to identify changes that can alter answer support.
Recompute the affected answers.
Measure both missed changes and needless recomputation.
Include additions that supply previously missing answers.
Otherwise, dependency tracking can miss new evidence outside the previous context.

This changes the target from raw accuracy to the cost of preserving accuracy during updates.
The potential contribution requires a new rule for semantic changes and missing dependencies.
Simple citation tracking, timestamps, or cache expiration are insufficient novelty.
This route retains the original concern about stale evidence.
It also gives a concrete use for repeated observations and preserved provenance.

It differs from the failed propagation route.
The dependencies belong to the system's actual answers.
The sources need not contain an independently published downstream assertion.
However, we must evaluate real questions and observed source updates.
We must not invent dependency chains or source histories.

Kill this route if full reruns are cheap or ordinary dependency tracking achieves the same cost-quality result.
Also kill it if improvements depend on missing answer-changing additions or weaker readers.
FreshCache already studies freshness risk, so generic risk-aware cache reuse is not a sufficient contribution.

Pivot 2: Selective replacement under uncertain temporal scope.

Research question: Can a system remove stale evidence without deleting evidence that still answers a different temporal question?
Predict a replacement relation conditional on the question's time and scope.
Distinguish replacement, historical retelling, planned change, concurrent values, and unsupported disagreement.
Keep uncertainty when source evidence cannot support deletion.
Evaluate both corrected answers and damage to previously correct answers.

This addresses the original hard mask's main risk.
It requires genuine source ambiguity and strong temporal baselines.
The earlier bounded temporal semantics can supply implementation components.
They cannot supply a fresh novelty claim.

Kill this route if Re3 or standard temporal entailment yields the same improvement.
Kill it if a simple relevance filter removes the apparent advantage.
Kill it if the source collection supplies time intervals that decide every label.
Do not describe typed filtering or calibrated abstention alone as a breakthrough.

Pivot 3: A natural benchmark for harmful temporal deletion.

Research question: When does a newer document make a retriever wrongly discard useful older evidence?
Use existing natural questions and accessible document histories.
Measure lost support for historical questions, retained facts, and newly answered questions.
Compare complete readers, temporal filters, graph methods, and simple version selection.
Keep negative and unchanged cases in the denominator.
Measure errors at the history level.

This could support a focused empirical paper if the failure is large, reproducible, and poorly measured elsewhere.
It does not require a new optimizer.
It does require substantially better evidence than the current curated probes.
The user seeks method novelty and superiority, so this is a fallback route.

Kill this route if existing benchmarks already measure the same error with adequate sources and labels.
Kill it if the findings disappear with a strong reader or competent temporal retrieval.
Kill it if most histories require reconstructed source text or unverifiable chronology.

Correction to the earlier ambiguity gate

The v07 gate required competing readings to remain defensible after inspecting all source context.
That gate addresses unresolved ambiguity in the source itself.
It is suitable for testing uncertainty that available evidence cannot resolve.
It is not a necessary condition for learning to correct extraction errors.

A model can prefer the wrong entity, time, or scope after reading one passage.
Another real passage can resolve that error.
The wrong candidate need not remain defensible after both passages are read.
Its presence measures uncertainty in the model, not ambiguity in the complete source.
Requiring both readings to remain valid can exclude the very cases that joint interpretation should correct.

The revised discovery gate must separate three cases.
First, the source itself remains ambiguous after all eligible evidence.
Second, a local model makes an error that additional eligible evidence resolves.
Third, the candidate inventory omits the correct interpretation entirely.
The first case requires uncertainty preservation.
The second case can test joint interpretation learning.
The third case requires proposal repair and cannot establish a decoding gain.

This correction does not invalidate the old recorded results.
The earlier selected histories did not demonstrate useful joint inference.
It changes what a new, explicitly different experiment should seek.
Preserve the v07 protocol and its outcomes.
Do not retroactively count rejected candidates as successful experiments.

Narrow candidate: learn to revise temporal interpretations using retrieved evidence

Start with natural passages and real questions from an existing benchmark.
Retain a small candidate set for entity, scope, and time interpretations.
Generate candidates without reference answers.
Record the initial interpretation before retrieving additional evidence.
Retrieve passages that address the unresolved field or conflict.
Use those passages to revise the interpretation and its associated temporal links together.
The reader then receives the resulting source evidence and explicit uncertainty.

For example, a later document can describe an earlier event.
The model can initially mistake the document date for the event date.
Another passage can identify the event and its effective date.
Joint revision can change both the temporal interpretation and the proposed replacement relation.
This example states a mechanism, not an observed result in a new benchmark.

A fixed extraction pipeline cannot make this correction through filtering alone.
Once it assigns the wrong scope or time, a filter acts on the wrong fact representation.
A joint model can change that representation after receiving relevant evidence.
This potential difference is more substantial than adding another retrieval score.
It still requires evidence of better answers or equal accuracy at lower cost.

Use a shared encoder or small adapter to score candidate interpretations and their compatibility with retrieved passages.
Train with reference interpretations only where the training split supplies reliable labels.
Keep latent assignments where several supported interpretations yield the same reference answer.
Answer supervision alone can reward incorrect reasoning that accidentally reaches the correct value.
Therefore, retain evidence and interpretation checks alongside answer loss.

Compare independent training, independent decoding, iterative revision, and joint training under the same candidates and evidence.
Include a strong reader that directly sees all retrieved passages.
Include standard constrained prediction with the same compatibility rules.
Compare a second extraction pass after retrieval.
Otherwise, an ordinary retry could explain the improvement.
Measure candidate recall before measuring the benefit from joint selection.
Report errors that move from correct to incorrect after revision.

What this candidate does not establish

Joint temporal extraction is established prior work.
Han and colleagues already combine event extraction and temporal links through structured prediction.
IA-RAG already uses interval constraints and tightens uncertain times.
CoRM-RAG already learns an evidence critic from query perturbations.
Latent answer supervision also has established precedents.
Thus, joint learning, temporal constraints, and critic training are not sufficient novelty claims.

The unresolved contribution would require a precise learning mechanism for evidence-driven revision across entity, scope, and time.
It must improve on ordinary re-extraction and standard joint prediction.
The present code has no evidence that such a mechanism wins.

A capped discovery pass

Freeze at most 24 natural questions across at most six document histories.
Use existing natural source collections, not the financial certificate collection.
Choose the sampling rule before inspecting model errors.
Preserve ordinary cases as well as difficult cases.
Do not require publisher corrections or independently published downstream assertions.
Do not write artificial source contradictions.

Save initial model interpretations before additional retrieval.
Check candidate recall and source support separately.
Then determine whether real additional passages resolve observed extraction errors.
Record whether an ordinary second extraction pass already fixes each error.
Treat this pass as development evidence, not a held-out benchmark.

Stop if few natural errors require interpretation revision.
Stop if reference-free proposals usually omit the correct interpretation.
Stop if ordinary re-extraction resolves the same errors at comparable cost.
Stop if the proposed training rule only restates an existing structured learning method.
Only surviving evidence should justify model training or a larger empirical program.
