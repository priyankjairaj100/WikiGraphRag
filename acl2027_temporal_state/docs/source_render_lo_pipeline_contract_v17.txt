Source-block LibreOffice inspection v17

Published v16 artifacts are immutable. This amendment continues the exact source
assembly, passive resource refusal profile, Unicode metadata, page-cap sentinel,
output bounds and small-process resource policy of v16.2. The only execution
change is verified owned-process-group cleanup: after bounded TERM and KILL
phases, the group must be absent or namespace-anchored telemetry must show only
terminal/zombie members. Any unconfirmed cleanup latches a run-global refusal;
all remaining selected blocks stay in the denominator without further launches.
Signals use only the owned inner Popen PID created with start_new_session=True.
The shared frozen RSS helper binds its unique outer parent/group identity.

Resource policy remains the separately declared v16.2 small-process amendment:
512 MiB prelaunch reserve, 512 MiB summed owned-group RSS cap, conservative 7 GiB
proxy, unchanged 8 GiB kernel limit, run-global OOM-event baseline, no cgroup
writes. Actual cgroup total and proxy components are both recorded. Proxy terms
can overlap/double-count; samples are not continuous enforcement. Conversion
300 seconds, raster 60 seconds, 20 MB per block and 150 MB per attempt remain.

Run the exact saved Unicode and overflow fixtures first. A successful Unicode
text-presence check still requires visual review. The overflow control must
retain the max-pages-plus-one PDF as a failed incomplete render. No natural
render follows if either control or independent consumer/dependency gate fails.

Freeze every selected table and unique existing neighbor from amended pool
v16.1, retaining the original 13-table pool lineage. No source rewriting,
missing labels, numeric reconstruction, selection substitution or question
creation is allowed. Source-bearing outputs are external to Git; public receipts
contain only identities, hashes, status and bounded diagnostics. Existing paths
are never overwritten. Keep every failed/refused block in the public denominator.

LibreOffice does not establish browser CSS fidelity. Authored merged-cell
geometry passed, but borders and width differ. Each natural table and relevant
neighbors require actual raster/source review of all selected rows, header and
numeric-column mappings, units, captions, footnotes and material CSS visibility
or ordering effects. Empty hidden source cells remain in exact source markup.
Conversion success never grants question/reference admission automatically.
Images/external stylesheets/fonts are not fetched; resource-bearing assembled
markup is refused, source head style blocks and ancestor openings are preserved,
and omitted sibling/style dependencies remain a recorded limitation.
