Assessment

accumulator. A small aggregate excess is consistent with finite-precision
normalization and subsequent representation as log probabilities. This
review does not establish the precise contribution of each numerical step,
and 1e-4 is not a proved worst-case error bound. It is a fixed engineering
sanity threshold for this bounded diagnostic.

The change accepts aggregate mass up to 1.0001 for both the returned list
and the two literal labels. It preserves every native log probability,
Yes-minus-No log odds, zero decision threshold, prompt, label order and
model setting. There is no clamping, renormalization, calibration or choice
of a better scoring condition. Each result now exposes the actual returned
mass, literal-label mass and configured tolerance. The finite/nonpositive
log-probability, full-input, cold-cache and other prior checks remain.

This amendment follows a raw model output and must not be described as
zero-output preregistration. Its declared trigger was a numerical contract
failure; the parent received aggregate mass/error only, with per-item score
and reference-agreement analysis embargoed. All sixteen research calls are
restarted in new directories; the first row is neither reused nor silently
