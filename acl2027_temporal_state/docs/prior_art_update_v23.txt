Chris Martin, Reclassified to Conform, arXiv:2609.38754v1, submitted
2026-09-30. Primary sources inspected: abstract and HTML sections 3, 4 and 6.

The paper reconstructs statement-line histories across filings. It forms runs
from matching reported numbers, enumerates candidate edits, and uses integer
optimization to select compatible edits. It retains filing provenance and
discusses multiple explanations. Section 6 describes inputs from numeric facts,
declared arithmetic and string comparisons, and possible model-based extraction.
The reported evaluation is not independently reproduced here.

Research decision: cross-filing correspondence, candidate edit enumeration and
integer optimization are not sufficient novelty claims for this project. A
possible remaining question is whether acquiring explicit source explanations
for a requested relation improves supported answer yield at matched cost and
risk. That is a hypothesis, not an established difference or contribution.
Any future relational track must compare against this work where applicable,
as well as the v21 literature ledger. Code availability and executable baseline
compatibility have not been established. This targeted reading is not an
exhaustive overlap assessment of the 66-page paper.

XBRL International, Handling Duplicate Facts in XBRL and Inline XBRL 1.0,
Working Group Note, 2025-01-14, sections 3.3 and 9.
https://www.xbrl.org/WGN/xbrl-duplicates/WGN-2025-01-14/xbrl-duplicates-2025-01-14.html

The guidance distinguishes differing literal values from inconsistent facts:
rounding intervals can agree, while equal-accuracy reports must agree in value.
This makes a precision-aware typed baseline necessary. Our v23 source audit
is a bounded signed-interval screen with source locators, not full OIM/DTS
conformance or semantic adjudication. The historical magnitude-ratio result
must not be presented as a new conflict-resolution task.
