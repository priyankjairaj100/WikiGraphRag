Source audit v23: the next probe must leave the rounding-conflict route
===================================================================

Decision
--------
Do not promote the 41 representative same-binding disagreements into a
conflict-resolution benchmark. The exact sources support ordinary reporting
at different decimal accuracy. Continue with the separately scoped cross-filing
comparison probe, where source identity and conceptual correspondence must be
established explicitly. A text/table retrieval track is still conditional on a
real, fully specified question failing a competent typed/structural baseline.
This audit establishes no method win and admits no source tasks.

What was actually executed
--------------------------
A new recovery protocol was frozen before downloading the same twelve pinned
filings. All twelve sources matched their original SHA256 and byte count:
62,730,877 bytes total. Raw sources, parsed document caches and source excerpts
remain outside the repository. Historical recovery receipts were not changed.

A separate audit protocol was then frozen before parsing. The audit reproduced
23,414 eligible facts, every one of the 41 historical first-representative
conflicts, and all 87 full-binding conflict groups. The distinction matters:
v22's 47 conflict-bearing concepts, 41 representative failures and 87 conflicting
full bindings are different denominators.

Every one of the 87 groups has:
* overlapping signed numeric intervals under the stated decimals;
* at least one table occurrence and one prose occurrence;
* different scale attributes, but the same context ID and unit ID;
* a unique value at the highest reported decimal accuracy.

No group contains a zero or mixed-sign values. There are seven groups containing
negative values; these remained negative throughout the interval calculation.
There are no unequal values at equal accuracy. Direct lexical/sign/scale
arithmetic checks passed for all 191 conflicting fact occurrences.

The original audit uses a conservative closed-interval screen. The later,
explicitly post-audit check adds the equal-accuracy condition, preserving the
original protocol and results. All 87 groups have strict overlap, so no group
depends on an endpoint-only exception. This is reported as accuracy-compatible
source data, not as complete XBRL/taxonomy validation.

Assistant source review inspected the first occurrence of every distinct value
for all 41 representative probes (82 occurrences). The retrieved table/prose
passages support the rounding explanation. The review is assistant annotation,
not independent human gold, and did not include browser rendering. Byte offsets,
DOM paths and span hashes make every occurrence recoverable from the pinned body.

Illustrative derived metadata, without source-text redistribution:
* PFE 2023 Assets: 226,501,000,000 at decimals -6 versus 227,000,000,000 at -9.
* PFE 2023 IncomeTaxExpenseBenefit: -1,115,000,000 at -6 versus -1,100,000,000 at -8.
* NFLX 2022 ProceedsFromStockOptionsExercised: 35,746,000 at -3 versus 36,000,000 at -6.
* SLB 2023 Depreciation: 1,445,000,000 at -6 versus 1,400,000,000 at -8.

The normative background is already established domain practice. XBRL
International's 14 January 2025 Working Group Note, section 3.3, describes
consistent numeric duplicates using overlapping accuracy intervals with an
equal-accuracy equality constraint. Section 9 recommends retaining the most
accurate consistent occurrence for relevant processing. This is a required
competent baseline correction, not our algorithmic novelty.
https://www.xbrl.org/WGN/xbrl-duplicates/WGN-2025-01-14/xbrl-duplicates-2025-01-14.html
Accessed 2026-10-05. The note refers formal definitions to OIM; no broader
standards-conformance claim is made by this audit.

Cross-filing decision
---------------------
All six fixed issuer pairs were checked. Exact expanded-QName binding overlap
is zero. The namespace-erased diagnostic reproduces 5,629 shared binding keys,
of which 481 are not identical singleton values. These are diagnostic counts,
not admitted semantic joins or 481 restatements. Neither a local-name match nor
different literal values establish equivalent concepts, a genuine revision, or
a question that needs a certificate.

Each recovered HTML document has a relative schemaRef for its own dated XSD.
Those XSDs and label/reference linkbases are not present in this recovery. The
HTML base in the mirrored dataset is not evidence that the relative XSD can be
resolved from that mirror. No namespace was silently stripped to authorize an
answer. The next bounded probe should verify physical filing identity, same-period
row meaning, units, scope, and an explicit correspondence for each chosen metric.
Use the original annual-report dates: BRK-B_2022.html is FY2021 and BRK-B_2023.html
is FY2022. The filename discrepancy remains preserved.

The separate cross-filing probe agent owns the next concrete source questions.
Prior-art screening is also necessary: "Reclassified to Conform", arXiv
2609.38754, directly concerns successive financial statement correspondence.
This audit does not make a novelty claim for that route.

temporary directory, preserves every frozen file, and writes a separate output

successfully: documents, cross-filing pairs and totals exactly matched the
original v23 result. Existing outputs are refused. Keep the created external
working directory if parsed caches or review excerpts are needed.

These are development source checks. No model calls, held-out items, natural QA
