Reason for a separate resource policy

The shared cgroup's memory.current includes unmapped file cache. During the
original refusal, several GB of file cache coexisted with a much smaller mapped
footprint. Total-current accounting therefore refused even small local workers.
The policy below is an explicit changed resource condition, not evidence that
the original memory requirement was met. It applies to sequential Arelle
workers, not a native language-model reader.

The kernel cgroup documentation consulted by the root agent is
https://docs.kernel.org/admin-guide/cgroup-v2.html (memory.current, memory.stat,
memory.max and memory.events). This amendment does not alter kernel controls.

Frozen policy

- Require memory.max to remain exactly 8 GiB (8,589,934,592 bytes).
- Define a conservative pressure proxy as the sum of anon, file_mapped, shmem,
  kernel, sock, file_dirty, file_writeback, unevictable and swapcached from
  memory.stat. Overlapping fields are deliberately counted more than once.
- Before every source launch, require proxy + 2 GiB worker reserve < 7 GiB.
- Monitor one worker at a time at 0.1-second intervals. Stop its process group
  when the proxy reaches 7 GiB, worker RSS exceeds 2 GiB, wall time exceeds
  300 seconds, or free shared memory falls below 256 MiB.
- Record one run-global OOM/OOM-kill baseline before the source loop. Refuse or
  stop on any new oom or oom_kill event, including between source attempts, or
  if a counter decreases. Preserve the all-12 denominator.
- Missing or malformed required telemetry, a changed/unlimited kernel max, or
  an unreadable baseline fails closed. No cgroup setting is written, no cache
  is evicted, and no unrelated process is signaled.
- Record actual memory.current, each of the nine components, proxy, OOM
  counters, worker RSS, prelaunch/final snapshots and sampled peaks. Every
  monitoring sample remains in an external, hash-bound JSONL receipt.

This is a polled watchdog, not a hard per-process memory sandbox. Consecutive
kernel reads are not atomic. Sampling can miss transient peaks. The proxy is
neither exact resident memory nor a formal bound on every unreclaimable
allocation. Actual total memory may exceed the old 7.25 GiB soft threshold;
the amended result must not claim otherwise.

versioned renderer, whose own reserve/RSS policy must be stated independently.
scripts/run_full_dts_v16_2.py reuses unchanged sources, taxonomy cache, SEC

results/full_dts_v16_2.json. Existing code, protocols and results remain intact.
