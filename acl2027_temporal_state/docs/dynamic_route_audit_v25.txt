Dynamic research route audit, v25
Audit date: 2026-10-06
Role: literature review and prospective design only.
No new model experiment was run.
No new dataset was collected.

Decision

Do not restart the project as another temporal graph system.
Current work already covers time-aware retrieval, graph updates, interval reasoning, and temporal preference training.
These components cannot support our novelty claim by themselves.
The strongest remaining hypothesis concerns retrieval decisions under unresolved temporal evidence.
This hypothesis needs a small failure audit before implementation.
The current financial probe does not establish this failure.

Candidate question

Can retrieval resolve the temporal relation that changes an answer, instead of retrieving more facts from familiar periods?
The candidate method would maintain alternative interpretations of a temporal relation.
It would request evidence that distinguishes those interpretations.
It would preserve alternatives until source evidence removes them.
For example, a document can describe publication time, event time, or the validity of a continuing state.
These times can differ.
A missing relation can determine whether two individually relevant facts support the same answer.
This is a research hypothesis, not a verified gap.
Query decomposition, temporal filtering, and uncertainty alone are established ideas.

Discriminating experiment

Freeze 60 TEMPO development questions before comparing methods.
Select them by existing task labels and domain, not by baseline failure.
Keep all selected questions in the report.
First inspect whether source evidence supports a temporal relation that document dates cannot determine.
Record questions with no such relation as controls.
Do not infer global absence from an unsuccessful source search.

Give all methods the same initial candidate passages, reader, token budget, and maximum retrieval calls.
Compare a strong dense retriever, MRAG, ordinary iterative decomposition, Chronos, and an IA-RAG implementation.
Label any IA-RAG reconstruction as a reconstruction until authors' code becomes available.
Include a control that resolves all dates and relations from reviewed references.
This control separates extraction failure from retrieval policy failure.
Do not give reference relations to only our method.

The proposed method must select evidence that resolves alternative temporal interpretations.
Compare it with ordinary decomposition using the same relation extractor.
Measure complete evidence coverage, answer accuracy, unsupported answers, and total cost.
Review cases where document recall disagrees with semantic evidence coverage.
Published labels may omit valid alternative evidence.
Do not count these alternatives as retrieval errors.

The main test concerns the interaction between unresolved relations and the proposed acquisition rule.
A generic accuracy gain is insufficient to identify this mechanism.
An advantage caused only by larger context or extra reader calls does not qualify.
Use untouched domains for confirmation after the development method is frozen.
Do not represent this proposed split as an existing held-out result.

Local feasibility

A small embedding model and a quantized 7B–8B reader provide a plausible initial path on 20 GB.
This is an engineering estimate, not a measured runtime result.
Run embedding and reader stages separately.
Use disk-backed indexes and cached candidates.
Start with fixed domain corpora, then report the full benchmark if the mechanism survives.
Do not present a reduced corpus as a full benchmark result.
Freeze the reader and verify complete-evidence competence before interpreting downstream gains.

Fatal overlap and stop tests

Stop this route if IA-RAG already acquires evidence to resolve competing interval interpretations under the same objective.
Stop if ordinary decomposition with identical extraction removes the advantage.
Stop if reviewed natural questions rarely require the proposed relation decision.
Stop if gains occur only on generated perturbations or oracle relations.
Stop if the method suppresses correct alternatives and thereby increases unsupported answers.
Stop if full-source evidence cannot establish reliable reference relations.
Do not continue from a few selected success cases.

Recommendation to the project lead

This audit does not identify a verified breakthrough for dynamic lifecycle management.
It identifies a narrow, falsifiable acquisition hypothesis on real questions.
Treat it as a competing candidate, not the default next implementation.
A route with clearer source evidence and less recent overlap should receive priority.

Focused addendum: learning which evidence changes an interpretation

Decision: reject the current formulation as an algorithmic contribution.
The formulation identifies a useful problem, but it currently combines known operations.
It does not yet supply a mechanism that distinguishes the paper from those operations.

Re3 is a closer competitor than a generic temporal retriever.
URL: https://aclanthology.org/2026.acl-long.1180.pdf
Inspected: sections 3.1–3.4 and benchmark construction in section 4.1.
Re3 groups extracted facts by entity and relation.
It selects the newest conflicting value through publication time, then removes documents supporting other values.
Its stated setting assumes authoritative sources where the newest version supplies current truth.
This gives a precise distinction: apparent conflicts can concern different scopes, so neither value necessarily replaces the other.
However, adding scope fields and applying the same rule is an ordinary correction to the representation.
It does not establish a new acquisition algorithm.
Re2 Bench also generates documents and questions from tuples, including perturbed negatives.
Thus, it cannot supply our main natural-language evidence without separate source validation.
Browser references: turn467view0, turn469view0.

IA-RAG already includes uncertain intervals and refinement through logical constraints.
A method that retrieves a missing temporal boundary and tightens intervals risks direct overlap.
The full paper remains inaccessible through the attempted fetches.
Its abstract and official description support this overlap concern.
They do not establish whether its acquisition policy handles competing scope assignments.
That detail remains unknown.

MRAG already decomposes temporal questions and combines semantic and temporal evidence scores.
I additionally inspected its full method and retrieval analysis.
Source: https://aclanthology.org/2025.findings-emnlp.167.pdf
An extra query asking for a missing scope definition is a decomposition step.
Calling that step interpretation repair does not change the algorithm.
Browser references: turn469view1, turn470view2, turn470view3.

EC2 already selects costly tests that distinguish answer-equivalent hypotheses.
Source: https://www.cs.cmu.edu/~dgolovin/papers/nips10.pdf
Inspected: sections 2–4, including the objective and approximation theorem.
Its input includes hypotheses, tests, outcomes, costs, and a probabilistic model.
Mapping temporal interpretations to hypotheses and source requests to tests directly instantiates this established problem.
Replacing exact test probabilities with learned estimates does not create a new objective or transfer its guarantee.
Our present challenge is constructing reliable interpretations and test outcomes from source text.
The current project has not solved that challenge.
Browser references: turn470view0, turn472view0, turn472view2.

What would change this decision

A distinct candidate would jointly learn scope assignments and the effects of acquiring evidence on those assignments.
Its training target would concern valid changes between interpretations, not merely passage relevance or reader confidence.
It would need natural examples where the same passage has different value under different unresolved interpretations.
It would also need examples where new evidence preserves both values because their scopes differ.
These labels must come from source-supported relations, not from whichever answer the reader prefers.
This describes a missing research object, not a completed method or a verified novel mechanism.

The decisive control is the same learned representation with ordinary decomposition and EC2-style selection.
If those controls match the candidate, the claimed acquisition contribution disappears.
A scope extraction improvement could still support a paper, but that requires its own method and substantial transfer results.
Do not spend the next implementation budget on a renamed combination of these components.
