Paired-reader reference review v0.13

Eight natural-language development questions and their references are accepted before main predictions. The reviewer is a separate agent role from question authors and model execution, but shares project context and prior source familiarity. This is model-assisted review, not blinded assessment or independent human gold. No network, retrieval outputs or native predictions were used in this review.

The reviewer read actual captured-source page text for every listed sufficient set, checked five targeted rendered pages for financial-table alignment and scientific numerical/scope statements, and verified all four source-byte hashes. The review does not claim full-page visual inspection, scientific replication, global extraction fidelity or original-publication byte identity.

Plug's four questions concern revised loss and EPS, retained service revenue, the omitted-cost reason for a maintenance-contract loss accrual, and the distinction between the result year and report year. Each permits a sufficient answer from the later report alone. The old/restated table correctly gives the common-stockholder loss and EPS, rather than conflating company loss, service cost or report year. The stated cost omissions explain the accrual; no new arithmetic or causal attribution is invented.

OPERA's four questions concern the revised main arrival-time estimate, retained geodetic baseline, identified instrumental problems and changed event selection. The revised result and instrumental explanation can be supported by the later paper alone. Baseline retention and changed-selection comparisons need evidence of both compared versions unless another captured passage explicitly supports the comparison. Neither exact numeric recitation nor irrelevant detail is needed to manufacture a cross-version requirement. The reported result is compatibility within uncertainty, not proof of light-speed equality or a causal finding.

Three requested reference corrections were resolved before main predictions, without changing the questions: baseline uncertainty is optional when the question does not request it; old/new event totals are optional when the question asks how selection changed; and Plug's page-150 table requires the page-149 unit introduction (or equivalent verified unit evidence) to support million-dollar amounts. The author files retain earlier hashes and amendment rationales. Reference facts remain source-grounded. An answer may use a separately verified alternative passage rather than an exact listed page set.

Content, scope, citation support and format must be judged separately. Missing format does not erase correct semantic facts. Exact page overlap does not establish chunk support. Retain fact-level omissions and contradictions, distinguish retrieval from reading failure, and do not repair outputs or change references after observing them. Any alternative evidence acceptance must be documented as an adjudication, not a silent reference rewrite.

The separate control review accepts two authored short checks only. Passing them would license this bounded small-reader feasibility run; it would not certify a strong baseline. These eight development questions over two familiar histories establish neither a benchmark nor general performance or algorithmic novelty.
