results/reader_binding_blank_independent_review_v18.json. It permits exact empty

The population must equal the original ordered 21 source/table pairs. All 12
original typed/view inputs and all pool author files are hash/size checked before

conditioning is introduced. Source files themselves are not searched. Reusing
the exact saved full table inventories and typed records regenerates all selected
whole blocks and occurrences rather than truncating to an answer subset.

Exact parent comparisons, before each new private write

The 21 original combined bundle files and 21 separate author-staging files are
checked against the bound public SHA256/byte manifests; symlinks and non-basename
artifact paths are rejected. Every combined author's projection must equal its
separate export. Newly regenerated candidates must preserve, with exact string
and array equality under canonical JSON:
 - author_staging, including every block's original text, order, anchors and rows;
 - the complete question_free_registry and source_only_dependency_plan;
 - null question/reference data and unreleased/null-card flags;
 - the complete fact count/handle order and null population bindings;
 - each generated value/label against its unchanged registry entry, and every
   present binding/witness against copied declared metadata and its exact wording;
 - the compact v18 prompt round trip and exact block-handle/text order.

The new raw pack is then reconstructed with the original v16 schema and validated
with the frozen v16 class. Its complete gate must match both the parent's private
gate and public inventory gate. For the original ten successful packs, every pack
field must also match after that schema substitution. The original eleven failed
packs must again yield the same failure and null candidate. The public successor
stores these comparisons alongside each new result; it does not edit the parent.

The source-only projection is not reinterpreted or released. Identity cards stay
null, author_release_allowed stays false, every population stays null, and visible
period/unit/scope verification stays false. Declared typed aspects remain explicitly
mechanical metadata rather than source-reviewed semantics. New shape success is
not permission to author questions or call a reader.

At completion the ordered 21 bundle IDs, exact 40-block dependency manifest and
19 blank exposures must match the parent. A changed registry/projection/gate,
unexpected v18 shape failure or population mismatch stops the run. No failed
comparison is repaired or silently skipped; any partial new external directory
is retained, and the same destination cannot be reused. The old sources, bundles
and receipts are never modified.
