Static native capacity calculation

results/reader_native_capacity_estimate_v17.json binds the actual GGUF structural
metadata and nine primary source files at the exact runtime commit. Eight full
attention layers at 8192 slots, four KV heads and 256-dimensional K/V, using
34 bytes per Q8_0 block of 32 elements, require 142,606,336 tensor bytes (136 MiB).
The 24 recurrent layers use F32 R/S despite the attention-cache Q8_0 settings:
their convolution states require 2,359,296 bytes and recurrent states 50,331,648
bytes for one sequence and zero rollback snapshots. Named cache tensors total
195,297,280 bytes (186.25 MiB), before alignment and bookkeeping. The zero-rollback
assumption must be checked against the native startup log, not silently assumed.

After the complete weight-file length and these cache tensors, the 4.25 GiB RSS
ceiling leaves 351,869,728 bytes (335.569 MiB) for the compute graph, tokenizer,
native libraries, CPU quantization/repacking workspace, stacks and other
allocations. Exact compute workspace is not known without initialization: the
pinned scheduler reserves prompt-processing and generation graphs with a
128-token microbatch. The sole loader attempt must retain the actual reported
buffer sizes and observed RSS. This residual is narrow; a guarded refusal or
allocation failure is a legitimate result, not grounds to relax caps or retry.

Proposed separate amendment for root review

Do not bypass the frozen driver's total guard or reset its failed attempt.
The separately named v17 driver/config are prepared for review and freezing.
Root must approve the exact frozen protocol before execution. This is a different
resource policy, not proof that the original limits passed or are equivalent.

The smallest bounded initial authorization would be one tokenizer-only native
session for the eight unchanged authored prompts, with zero completion calls:

1. Require the heavy-worker window to be idle. Verify exact model SHA with the
   existing 1 MiB streaming digest and DONTNEED every 32 MiB, and verify the exact
   runtime manifest. Do not evict unrelated caches or change cgroup settings.
   Record fresh memory components, events, current/max, and all proposed caps.
2. Before launch, require the conservative pressure proxy plus a 4.25 GiB owned
   group RSS reserve to be strictly below 7 GiB. At the recorded snapshot the
   sum is 7,371,366,400 bytes, leaving 144,826,368 bytes below that stop. This
   narrow margin can disappear before execution; a fresh failure must remain a
   refusal, with no automatic limit increase. This gate does not guarantee that
   the model fits. The 4.25 GiB RSS ceiling leaves only 547,167,008 bytes above
   the weight-file length for resident libraries and model state/workspace.
3. Launch in a new session and immediately capture the reviewed authoritative
   inner/outer process-group anchor. Use the unchanged shared RSS helper and
   results/owned_rss_audit_closure_v17.json. Enforce owned group RSS <4.25 GiB,
   conservative pressure proxy <7 GiB, RLIMIT_AS 5.5 GiB, wall/CPU limits, and
   fresh telemetry every 0.1 second. Missing live telemetry fails closed. Record
   actual memory.current, memory.max, and event deltas at every check. A watchdog
   guard failure sends SIGKILL immediately to the original inner process group,
   independently of any blocked HTTP call; final cleanup still verifies that
   no owned live process remains. Refuse
   current >= memory.max and stop on any new oom/oom_kill event; never describe
   the sampled watchdog as a hard kernel isolation guarantee. The original
   7.25 GiB total-current stop would explicitly not govern this separate policy.
4. Do not infer that all file cache is harmless. Kernel reclaim may be required
   while the model faults in. Stop at any guard/identity/timeout failure and
   retain it. Signal only the original inner process group; confirm no live
   owned descendants before releasing the heavy window.
5. If native health/identity succeeds, render and tokenize exactly the eight
   authored requests, retain complete prompts/token IDs externally, and apply
   the existing no-truncation limits. Stop after that one session. This result
   would establish loader/tokenizer feasibility only, not generation fit or
   reader competence. A later separately admitted authored eight-call gate
   would measure generation and interface behavior, with all failures retained.

No model session under this proposal has been authorized or executed by this
assessment. scripts/native_loader_v17.py and configs/native_loader_v17.json
implement the separate path. tests/test_native_loader_v17.py covers the pressure
formula, complete group accounting, prelaunch refusal, telemetry loss, blocked
HTTP watchdog enforcement, group cleanup, zero-generation endpoint whitelist,
one-attempt marker, and full eight-row success/failure accounting with authored
data and mocks. Its initial independent review found that a TERM-only watcher
could defer enforcement during blocked HTTP; the code now kills the owned group
immediately on watchdog failure and the regression is preserved in the suite.

The freeze command accepts only the fixed authored control file and copies
request messages only, never references, into an external attempt directory.
It pins code, tests, model identity, native configuration and profile, resource
evidence and request hashes before native execution. It does not hash the full
model until the sole approved run, whose prelaunch reserve must first pass.
The run command requires the root-approved frozen-protocol SHA256 and creates
an exclusive attempt-started marker. Both successful and failed attempts consume
that one attempt; repeated execution is refused. Public results retain all eight
request states, actual process/tokenizer/API counts and the private trace hash.

Cold-call recipe and research gates

Cold means a fresh native process and empty prompt/KV cache for each completion,
cache_prompt=false and cache_n=0; it is not a claim of globally cold disk cache.
Exact bytes, prompt/token identity, decoding, trace hashes, and all generated
token IDs stay pinned/retained. No completion repair, retry, or selective omission
is introduced. The authored gate remains eight calls, if later admitted.

An authored pass would still not admit natural questions automatically. Full
paired natural packs need their own frozen tokenizer-fit check and separate
semantic evidence admission. The v16 draft required issuer/slot parity order,
whereas its native path fixes adjacent B1 then B2. Root accepted the protocol
owner's explicit retention of fixed order with its latency/order confound
disclosed in v17; this change must be frozen before any natural calls. Do not
claim timing superiority from that schedule. Natural references must remain
outside prediction-worker inputs; the existing mixed host reference-loading
path needs separate review or separation before a natural protocol is admitted.

No stronger-reader, natural QA, binding benefit, or ACL publication claim follows
from this resource assessment or from a future loader/tokenizer pass.
