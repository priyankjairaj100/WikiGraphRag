\section{Evidence boundary}\label{sec:v10boundary}
This addendum reports a bounded source screen and annotation-conditioned support materialization. It reports no model predictions, general question-answering accuracy, or search-method improvement. Earlier scoring diagnostics remain unchanged. The planned eight-history empirical gate has not been completed.

Eighteen discovery queries screened twelve histories across corporate, scientific and technical domains. All eleven attempted full-document downloads failed before HTTP. A separately frozen follow-up retained four financial web-reader excerpt representations. These contain noncontiguous, sometimes overlapping line windows and tool metadata; they are not full publisher documents. Consequently, zero histories are admitted as full-prefix benchmark inputs. Access failure does not establish substantive source ineligibility. Screenshot responses provided no inspectable image data, leaving visual table verification outstanding.

\section{Source-grounded controls}\label{sec:v10controls}
Separate source-only review identified two usable excerpt-conditioned illustrations. Plug Power's FY2018 common-stockholder loss and basic/diluted loss per share were explicitly restated, with services revenue retained. Molson Coors' FY2017 attributable income and basic earnings per share were explicitly restated, with operating cashflow retained. Original computation or earnings/share evidence supports the old downstream dependency in each case. Fiscal scope, signed units and issuer attribution are preserved; rounded share figures are not used to claim exact numerical reconstruction. The source review is model-assisted and unversioned, not human benchmark gold.

Each annotation supplies five assertion records: old numerator $O$, replacement numerator $R$, old earnings-per-share assertion $D$, replacement assertion $E$, and unaffected control $U$. Both direct replacements, $R\!\to\!O$ and $E\!\to\!D$, remain available. The essential dependency $D\!\to\!O$ is grounded in the earlier source. The protocol clarification requiring all direct replacements was recorded after discovery leads and before execution; it is not represented as pre-discovery preregistration.

\section{Verification and reproducibility}\label{sec:v10verification}
All 377 unit tests pass, including eight new interface checks. Independent audit verifies ten source-derived assertions, four direct corrections, two essential edges and six policy states. Two temporary reruns reproduce the saved result files exactly. Four external source hashes and 32 evidence-span instances were checked. Packaged metadata permits offline binding and policy-record verification; exact source checking requires the omitted working excerpts and quote-bearing annotations. Raw annotations were retained before a provenance-only revision. Full-source download failures remain preserved.

\section{Research implication}\label{sec:v10route}
A bounded review of MQuAKE, Knowledge Update Playground/MCT, LongMemEval and Mem0 finds precedents for downstream consequences of edits and dynamic memory maintenance. This review is not exhaustive and establishes no novelty. The remaining hypothesis is whether source-grounded interpretation of correction targets and essential support improves answers while preserving unaffected evidence, beyond strong direct-update, contextual-reader and restarted iterative baselines.

Next experiments require complete admitted evidence, cases where downstream withdrawal is not already a direct correction, and a separate non-temporal support-answering contract. The current date-conditioned QA interface cannot provide definite numeric answers by turning unknown intervals into permanent truth. Alternative support, retraction, scope changes and numerical recomputation require explicit semantics rather than silent coercion. Exact search remains a bounded reference until its residual value is measured.
